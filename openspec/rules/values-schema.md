# Values、Schema 与用户配置规则

- 只为已实现且已验证的字段维护用户配置契约。
- 每个已实现字段在当前规格中记录类型、必填性、默认行为和关键约束。
- `values.schema.yaml` 是 Schema 维护源；发布时生成 Helm 使用的 `values.schema.json`，不得手工维护两份定义。
- 所有顶层字段声明类型；必填字段进入 `required`；枚举、互斥和依赖关系显式表达。
- [`values.yaml`](../../values.yaml) 字段说明包含类型、含义、是否必填和默认值。
- 保存最小有效输入、较完整有效输入和关键失败输入作为可复现验证资产。
- 探索期不要求为未触及的模板批量补齐 values、Schema 或用户文档。
- values、Schema、样例和用户文档不得包含密钥、令牌、证书或其他真实敏感信息。
