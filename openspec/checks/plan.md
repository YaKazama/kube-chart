# Plan 检查

- [ ] draft frontmatter 完整且与 change 路径、主要模板一致；正文包含目标、需求、约束、非目标、验收。
- [ ] 用户明确内容未被覆盖；所有 AI 草稿逐项标记 `[AI 推断]`。
- [ ] 显式目标、依赖和非目标边界清楚；未实现子模板未被展开为当前实现范围。
- [ ] 每条派生结论标明 draft、项目规则、代码事实或 AI 推断来源。
- [ ] `plan/spec.md` 记录匹配的 `draft-content-sha256`，只描述可观察行为，每个 Requirement 至少有一个 WHEN/THEN Scenario，并覆盖 draft 验收。
- [ ] `[AI 推断]` 未进入 MUST 或 SHALL；代码、规则和无关上下文未补全 draft 需求。
- [ ] `plan/design.md` 只在有重要技术决策时存在，不复述需求或通用规则。
- [ ] `plan/tasks.md` 简短、可执行，只覆盖当前显式目标和必要门禁。
- [ ] 待确认问题已作为明确修订建议报告，未以背景、历史决定或默认假设冒充用户需求。
- [ ] 存在 `[AI 推断]`、`[待补充]`、未决设计选择或验收缺口时 `status` 保持 `draft`；无阻塞项时才为 `planned`。
- [ ] 未修改正式代码、当前规格或 records。
