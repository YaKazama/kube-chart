# Release 执行提示

本文件只提示 `/ck-deploy` 的检查范围，不是发布证据。

- [ ] Chart 类型、Kubernetes 与 Helm 版本基线满足声明要求。
- [ ] 所有发布相关变更均已批准、应用、通过真实项目命令验证、完成人工 Review 并归档。
- [ ] 当前规格、实现、样例和用户可见行为一致。
- [ ] 通用规则位于 [`openspec/rules/`](../rules/)，能力专属行为位于当前规格，无重复规范来源。
- [ ] 使用仓库真实存在的项目命令确认核心样例可渲染，关键异常输入按规格失败；checklist 本身不作为证据。
- [ ] 无敏感信息硬编码，安全默认值符合项目规则。
- [ ] 发布涉及 values 时，[`values.yaml`](../../values.yaml)、Schema、[`docs/`](../../docs/) 和当前规格一致。
- [ ] [`openspec/changes/`](../changes/) 中不存在影响本次发布但尚未归档的变更。
