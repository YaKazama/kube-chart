目标: 新增命名模板 `definitions.APIGroup`，写入 `templates/api-resources/Definitions/_APIGroup.tpl`。
需求:
- 入参：唯一上下文 `.`。
- 行为：按 K8s API 规范字段顺序渲染 APIGroup 资源；不渲染 `status`、`metadata` 字段（APIGroup 在 K8s 中无 ObjectMeta 语义）。
- 字段：
  - `apiVersion`：string, 固定值 `meta/v1`，必填项，不允许覆盖。
  - `kind`：string, 固定值 `APIGroup`，必填项，不允许覆盖。
  - `name`：string, 必填项。
    - 遵循 RFC1035 Label 规范，由 `base.rfc 1035` 校验。
    - 最多 63 字符。
    - 示例：`example.com`。
  - `preferredVersion`：string, 可选。
    - 引用模板 `definitions.GroupVersionForDiscovery`。
    - 向下传递上下文为 dict 类型。
      - 示例：`dict "groupVersion" "meta/v1" "version" "v1.23.0"`。
    - 正则校验；正则分组到 `API_GROUP.GROUP_VERSION_DISCOVERY`。
      - 格式：`groupVersion(group/version) version`。
      - 示例：`meta/v1 v1.23.0`。
  - `serverAddressByClientCIDRs`：array([]string), 可选。
    - 引用模板 `definitions.ServerAddressByClientCIDR`。
      - 结果要去重、去空。示例：`mustUniq | mustCompact`。
      - 向下传递上下文为 dict 类型。
        - 示例：`dict "clientCIDR" "10.0.0.0/24" "serverAddress" "10.0.0.1"`。
        - `serverAddress` 可以是 hostname、hostname:port、IP 或 IP:port。
    - 正则校验；正则分组到 `API_GROUP.SERVER_ADDRESS_BY_CLIENT_CIDR`。
      - 格式：`clientCIDR serverAddress`。
      - 示例：`10.0.0.0/24 10.0.0.1`。
  - `versions`：array([]string), 必填项, 非空 (至少 1 个元素)。
    - 元素结构同 `preferredVersion` 字段。
    - 结果要去重、去空。示例：`mustUniq | mustCompact`。
    - 向下传递上下文为 dict 类型。
      - 示例：`dict "groupVersion" "meta/v1" "version" "v1.23.0"`。
- 边界行为：
  - 必填项缺失或值为 `nil`（`base.get` 返回字符串 `"null"`）时立即中断并报错。
  - 列表类型字段需通过 `base.isFromYamlArrayError` 兼容 Helm 4.2.2 `fromYamlArray` 对非列表输入返回错误切片的 BUG。
- 报错格式：`[definitions.APIGroup] 字段路径: 错误原因`。
