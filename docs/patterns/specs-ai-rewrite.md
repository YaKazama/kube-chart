# Spec 文档重写规范

## 适用范围

用于重写已有正式 SDD 文档。新建变更使用 `templates/spec-template.md`，不得混用。

## 核心原则

- 信息无损：保留仍有效的需求、约束、默认值、边界与参考资料。
- 契约唯一：通用规则引用 `patterns/`；单资源文档只定义专属行为。
- 边界显性：通用边界引用 `rules/const-boundary.md`，仅补充资源专属边界。
- 分层复用：不在单个正式 SDD 中重复通用能力和约束。
- 以实现为准：重写后必须与已验证代码一致；不得新增未经验证的业务规则。

## 输出要求

- 直接更新 `specs/` 中对应模板的唯一正式 SDD，或在变更工作区生成待 Review 版本。
- 正式 SDD 统一使用“身份与范围、依赖契约、输入契约、输出契约、专属边界行为、验收口径、参考资料”结构。
