# 历史参考资料

本目录保存旧实现、样例和资料快照，仅供开发者按需人工查阅与复制候选内容。

## 使用边界

- 本目录不是默认必读材料；AI 不得默认读取或根据其内容推断当前模板需求。
- 本目录不构成正式 SDD、通用规则或运行时模板的依赖；正式 SDD 不得引用本目录。
- 开发时由当前 `changes/<change-id>/spec.md` 显式列出所需的输入格式、正则、常量键、捕获组与使用位置。
- 审核确认后，将所需正则以全大写下划线嵌套键写入 `templates/base/_env.tpl`；该文件是唯一运行时常量来源。
- 目标模板只能读取当前 Spec 明确列出的常量键，并通过正常、边界和失败输入验证其行为。

## 内容索引

| `base/_env.tpl` | `docs-bak/samples/_env.tpl` | 历史正则与常量写法参考；按需摘取，不可整体迁入。 |

## 正则迁移

1. 在当前变更 Spec 中记录输入格式、正则文本、常量键、捕获组语义和目标模板。
2. 将已确认的正则写入 `templates/base/_env.tpl`，键名遵守全大写下划线嵌套结构。
3. 目标模板通过 `include "base.env" "" | fromYaml` 读取对应常量，不得内联重复正则。
4. 使用 `/opt/homebrew/bin/helm` 验证正常、边界和失败输入；模板修改完成后执行 `helm lint`。
