- 入参：dict
- 字段：

行为：
- 行为/设计说明，主要是处理逻辑
边界：
- 引用 `docs/rules/const-boundary.md`
- `<field-name>`: 字段边界说明
约束:
- 引用 `docs/rules/const-general.md`
- 允许读取`参考`提供的 URL ，通过 Field 和 Description 确认是否必填项及正则校验、可用设置、默认值、数量限制等

- API：
  - `https://kubernetes.io/docs/reference/kubernetes-api/` 下具体的 API 文档路径
